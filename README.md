# Akhilesh Vankayala — Portfolio Redesign

Crency-inspired, clean portfolio. Cream × ink × lime, oversized Anton type,
scroll parallax (GSAP ScrollTrigger), subtle 3D tilt on cards, marquees,
vibe + contact pickers. No WebGL/3D model — fast and neat.

## Run locally
No build step — static files:
- `index.html` · `styles.css` · `main.js`

```bash
cd C:/Users/Akhi/Desktop/portfolio_redesign
python -m http.server 5173
# open http://localhost:5173
```

## Deploy (Vercel)
Static, no framework preset. Only CDN deps: GSAP 3.12 + Google Fonts.
